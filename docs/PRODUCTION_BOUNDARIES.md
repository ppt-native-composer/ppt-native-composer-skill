# Production Boundaries

## What the Toolchain Does

- structure approved copy into editable PPT production objects;
- assemble valid PPTX files and inspect packages;
- preserve editable source text through EVC reconciliation;
- manage asset references and integrity checks;
- produce immutable runtime evidence and cache-aware staged runs;
- report mechanical and advisory layout conditions.

## What It Does Not Do

- autonomously create client-grade art direction;
- infer a final visual system from a short brief or public reference alone;
- make licensing or usage rights decisions;
- use public portfolio images as production assets;
- replace human visual review.

## Approved Artwork Workflow

1. A human designer or art director approves a flat comp or source artwork.
2. The project records asset provenance and permitted use.
3. The toolchain reconstructs official text and revision-prone information as native PPT objects.
4. Complex artwork may remain raster/vector assets, but a screenshot containing final baked copy is not treated as editable output.
5. Mechanical QA and human visual review are both required before delivery.
